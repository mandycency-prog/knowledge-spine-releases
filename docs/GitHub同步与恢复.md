# GitHub 同步与恢复

当前源码、通用说明和 Releases 统一在 `mandycency-prog/knowledge-spine-releases` 公开维护。默认分支 `main`，可见性策略 PUBLIC。开发继续在本机，用户资料与正式 App 保持原位置。

## 正常同步

完成更新使用 `python3 scripts/repo_sync.py finish`，或在完成对应检查后明确选择文件提交；post-commit 自动同步当前分支，pre-push 检查所有实际上传对象。最后运行 `python3 scripts/repo_sync.py status --require-synced`，核对远端哈希、工作区、自动同步及本地隐私检查。

新克隆运行 install 启用本地 hooks；授权由 GitHub 官方浏览器和本机凭据工具处理，不向聊天提供密码或验证码。可见性与固定仓库不匹配时拒绝上传，不能静默更换目标。

## 内容边界

正式数据库、录音、逐字稿、真实导图、原图、导出文件、课程名称、私人思考、诊断与密钥留本地。工具只读 sessions 生成本地散列指纹，不上传正文、不读 settings/Keychain。图片说明与识别文字也纳入指纹。没有本机资料的新克隆仍须做路径、凭据和人工审查。

## 原历史与恢复

原开发仓库继续私有，仅作历史备份。本次公开仓库承接的是审查过的当前源码及原先已公开的说明历史，没有公开旧私有提交。原本地分支和恢复包保留，不删除私人原件。

不要将私有备份分支或旧克隆直接推回公开仓库。公开审查默认覆盖当前历史，pre-push 额外覆盖每个实际上传对象；需要恢复代码时，在独立目录检查旧版本，仅提取必要的通用代码并重新审查。

正常开发不强推；失败保留本地版本并由 AI 处理后重试。
