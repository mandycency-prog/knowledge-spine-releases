# 安装限制与首次使用

版本：0.3.1-preview.1 · Apple 芯片 Mac · macOS 14 及以上

## 安装前须知

本版本只有本地测试签名，**没有 Developer ID 开发者签名，也没有 Apple 公证**。macOS 对网上下载的软件进行首次启动检查时会拦截，可能显示“无法验证开发者”或“Apple 无法检查是否包含恶意软件”等提示。不能保证所有机器或组织管理的设备都允许试用。

这次完成的是同一台 Mac 上的空白环境、移动路径和镜像安装验证；尚未在第二台实体 Mac 或 macOS 14 真机验收。系统音频权限和录制链路也未完成另一台电脑的验收。愿意接受这些限制时再试用。

## 安装

1. 从[本版本发布页](https://github.com/mandycency-prog/knowledge-spine-releases/releases/tag/v0.3.1-preview.1)下载 `KnowledgeSpine-0.3.1-preview.1-macOS-arm64.dmg`，可同时下载 `.sha256` 核对文件。
2. 打开 DMG，将“直播与课程知识骨架测试版.app”拖到 Applications，或复制到自己的测试文件夹，再打开应用。
3. 若遇到未识别开发者/未公证的拦截，只在你确认来源可信且文件完整后，自行决定是否按 Apple 官方方法打开：先尝试启动，然后到“系统设置 → 隐私与安全性”，查看是否出现该应用的“仍要打开”，并核对应用名称后确认。
4. 若没有这个选项，不要关闭全局安全保护或运行来源不明的解锁脚本；可暂缓使用。若提示损坏、恶意软件或授权被撤销，不应一概当作普通未签名提示处理，请停止并检查下载或反馈。

以 [Apple 官方安全说明](https://support.apple.com/102445) 为准，具体提示文字随系统版本而异。本软件不要求关闭 Gatekeeper、SIP 或其他系统安全保护。

## 首次设置

首次是空白资料库，语音转写所需的运行环境和 Whisper 基础模型已内置，不需要 Homebrew、Python 安装或终端操作。使用本机语音资源时优先采用系统已经具备的中文识别；不可用时使用随包基础模型。

**生成导图、校订和专题整理仍需要你自己的 AI 配置。** 在“模型与设置”中选择应用支持的 API 分析方式，填写服务地址和模型名、保存自己的密钥，并阅读、确认文字发送授权；可以使用“测试连接”，该测试可能消耗少量 API 费用。或者在本地模式下设置自己提供的兼容 GGUF 结构模型路径；包内没有附带大型整理模型，内存需求由模型决定。

录制声音时，按 macOS 提示授予应用必要的屏幕/系统音频权限，并只选择你希望记录的来源。拒绝或缺少权限会影响录音。首次看到权限提示不等于录制已经成功，应检查保存的音频和转写结果。

## 保存与更新

资料位于当前用户的 `~/Library/Application Support/直播与课程知识骨架测试版`。API 密钥保存在使用者自己的 macOS 钥匙串。测试版与其他正式安装版的资料和密钥存储独立。

更新请从本仓库 Releases 获取，更新前自行备份重要资料。当前应用没有内置自动升级功能。删除应用本身不会自动清理上述资料目录；请在确认备份后自行决定是否保留资料。
