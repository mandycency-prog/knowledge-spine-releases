# 课件图片的保存、分析与回查

在记录中点“图片”可管理课件截图，支持选择文件、拖入图片文件或图片数据、粘贴复制的截图。将图片直接拖到节点或逐字稿段落可关联该处；录制时默认参考当前录音时间。稍后添加的图片默认属于整场记录，不推测视频中的拍摄时间。

原图独立保存在该记录的 Images 目录，不依赖桌面文件。详情中可放大原图、写说明、更改关联。删除只改变图片的可见状态，可在图库“最近删除”恢复；已引用该图片的历史导图和版本仍能回查原图。

## 模型配置

在“模型与设置”填写独立的图片 API 地址、支持识图的模型名称与密钥，并确认发送图片及相关文字的授权。服务须兼容 Chat Completions 的 image_url 图文消息和相应结构化输出参数；仅有文字接口不够。密钥保存于本机钥匙串；同地址的文字和图片模型可复用同一密钥。

“检测实际识图能力”发送程序生成的随机数字图片，不使用课程材料。模型必须正确读出随机数字才显示检测通过。该检测证明输入链路可用，不代表所有图表、细小文字或公式都能准确理解。

识图没有自动选定供应商，也不额外下载视觉模型。应用以总览图及有界的细节区域发送图片，原图保持清晰版本。图像解读逐张处理、保存检查点，不自动重试收费请求。失败时已有原图、录音、稿件和完成的图片分析保留。

## 整理与来源

可先点击“分析图片”，再生成导图或专题；直接整理时也会带入当前图片。程序将图片解读与相关讲话共同作为材料。图片独有的信息可进入知识节点；图片中的疑点须保留，图片解读不能标为讲者原话。原始逐字稿不会被图片文字替换。

节点或专题中的图片来源可点开回查。图片标题、说明、识别文字、解释和疑点可在知识库搜索。说明、关联的实际文字或识图配置改变时，缓存不再匹配；只是打开图片查看不会重新调用模型。

每张静态原图限 20 MB、单边 20000 像素、总 5000 万像素，每场最多 50 张（含可恢复图片）。不支持的类型、损坏图像和超限图片会显示错误，不将空附件当作导入成功。

## 导出和合并

可编辑导图包 v2 携带去重后的原图，并重新映射导入副本中的图片、原文和节点关联；仍可读取 v1 文字包。单个包最多 32 MB，图片较多时可分场导出。合并知识时另行复制所需原图，保留原记录出处，不依赖原课程始终存在。

Markdown 导出的图片使用相对链接，需与同批次 Images 文件夹一起保留。PDF 在文字之后附上图片页，原始图片文件也留在导出目录。导出不会包含录音、API 设置或密钥。
