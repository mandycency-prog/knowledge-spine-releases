# 资料与隐私

## 安装包内容

预览包按明确清单组装，包含应用程序、运行后端、新准备的第三方运行环境、公开的 Whisper 基础模型、依赖许可及 FFmpeg 对应源码归档。首次启动为空白资料库。

本次发布未打包开发者的个人课程、导图、录音、逐字稿、正式数据库、API 密钥、旧恢复记录或私人开发文档。包内运行代码可以被接收者查看或分析；保持开发仓库私有不等于安装包不可分析。

## 使用者的数据

- 音频、逐字稿、导图、思考和版本保存在使用者本机的测试版资料目录。
- 本地模式使用本机语音和使用者选择的本地整理模型。
- 选择 API 模式并确认授权后，主动发起的任务所需文字（可能包括逐字稿、问题及相关思考）会发送给配置的服务商；不会把音频作为这些 API 文字请求的附件。
- API 密钥由使用者自行配置，保存于其 Mac 钥匙串。服务商自身的隐私、留存和收费规则须由使用者确认。

## GitHub 反馈

仓库、Issues 和附件是公开的。请勿把真实课程、录音、导图、密钥或原始运行日志直接附在问题单中；先删去私人信息，尽可能用合成示例说明。公开上传的信息可能被其他人保存。

## 第三方组件

应用内 `Contents/Resources/ThirdPartyNotices` 保存 FFmpeg 对应源码归档、相关许可及说明。Python 及各依赖包的许可证随运行环境保留在相应目录。Whisper 基础模型采用官方公开权重，并核对了官方 SHA-256。

本预览版未经过 Apple 公证；私人内容检查和功能测试不能替代 Apple 安全验证或使用者自身判断。
