# 测试版分发

当前方案（2026-11-06）：公开仓库同时保存已审查源码、说明和 Releases 安装包。原开发历史保留为私有备份，私人资料不移动、不删除、不上传。当前安装包仍是 0.4.0-preview.1，未获 Developer ID 签名或 Apple 公证，安装限制保持原说明。

## 系统与首次使用

测试版面向 Apple 芯片 Mac，macOS 14 或更高。语音识别所需 Python、FFmpeg、Whisper 基础模型已随包提供，不要求 Homebrew、终端或开发工具。

测试版与正式版使用不同应用身份、资料目录和 API 密钥服务。首次启动为空白资料库，不会读取正式版记录或密钥。使用者自行授予所选应用声音的录制权限。

AI 整理需要使用者在现有设置页配置自己的 API 服务、密钥并确认发送授权，或选择自己提供的兼容 GGUF 本地模型。包内包含本地推理运行库，未包含大型整理模型和任何个人密钥。软件不会自动配置收费服务或自动上传旧资料。图片分析需要独立配置兼容图文 API 并确认发送图片及相关文字的授权，不会自动下载视觉模型。

## 构建

先准备一个全新的 Python 3.11 arm64 独立运行目录，再安装 requirements-distribution.txt。不得把开发者日常 Python 环境整体复制过来。Python 独立构建来源为 astral-sh/python-build-standalone 官方发布；包内保留其许可证。

FFmpeg 从官方源码构建，不开启 GPL/nonfree 或第三方编解码依赖，禁用网络；保留对应源码归档、构建参数和 LGPL 通知。Whisper base 模型按官方 SHA-256 核对。

执行 scripts/package_distribution.py，明确指定新运行目录、FFmpeg、公开模型、FFmpeg 源码、Swift 构建目录以及一个不存在的输出目录。应用版本从 Info.plist 继承，可通过 --build-number 明确本次构建编号；不要在脚本中固定旧版本。脚本只复制固定后端清单和刚准备的依赖，不读取资料库、录音、钥匙串或整个项目目录。运行时和应用均使用相对安装位置解析。

本地隔离检查不能冒充已在另一台实体 Mac 实测。无 Developer ID 签名及 Apple 公证时，系统下载后的默认启动检查会拒绝；不得声称已具备无提示的普通用户分发体验。正式公开前须解决此项或由用户明确决定采用有说明的测试分发方式。
