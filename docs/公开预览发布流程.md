## 源码同步

只有审查后的源码、合成测试、构建工具和通用说明进入 Git。资料目录、原图、录音、导图包、密钥、备份、私人报告和旧私有历史不上传。常规更新审查完整当前历史和实际发出对象，核验目标仓库、PUBLIC 可见性以及上传后的哈希。

## 安装包发布

1. 从固定文件清单构建，验证真实隔离、保存重读、依赖和私人内容。检查不能由静态声明代替。
2. 审阅公开介绍、发布说明、截图和附件；私人指纹仅留 `.git`。
3. 新版本创建 tag 和 draft prerelease，上传明确附件，核对名称、长度与服务端摘要，再发布为 prerelease。安装包不进 Git 历史，不覆盖旧版附件。
4. 预发布版使用明确 tag URL，不依赖 releases/latest。发布后以不带登录凭据的请求验证页面与完整附件下载，重新核对 SHA-256。
5. 不强推、不复制旧私有引用。源码更新不自动冒充安装包更新；新安装包需完成该版本的相应检查。
