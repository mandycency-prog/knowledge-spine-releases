# 验证记录与边界

本预览包于 2026-10-22 完成构建和以下验证，2026-10-23 复核文件校验值后发布。以下项目是本机隔离测试结果，不是另一台实体电脑的验收记录。

- 项目 338 项 Python 回归、Swift release 构建及核心自检通过。
- 专项测试覆盖移动安装目录、中文与空格路径、新用户默认路径和原有自定义设置保留。
- 从最终 DMG 挂载后将应用复制到新位置，在空白环境实际启动、保存并重读合成资料。
- 实际打开界面显示“0 张图”。
- 使用包内 Python、FFmpeg 和 Whisper，在全新 HOME、仅系统 PATH 环境中实际识别合成中文音频。
- 包内真实后端通过 21 项合成 API 测试，含本机服务真实请求，未使用个人密钥或付费服务。
- 检查 110 个原生程序和库，未发现非系统绝对路径的外部动态库依赖；所声明的最低系统目标最高为 macOS 14。
