# 验证记录与边界

0.4.0-preview.1 于 2026-11-02 从当前源码构建。以下为同一台 Mac 上的隔离验证，未在第二台实体 Mac 或 macOS 14 真机验收。

- 356 项 Python 回归、Swift release 构建和核心自检通过。
- 图片核心 34 项检查、应用服务流程 45 项检查通过：合成图片导入、复制保存、重启读取、删除恢复、图文来源、导图包、Markdown 和 PDF 导出。使用独立临时记录及模拟模型，不使用私人课程或钥匙串。
- 从最终 DMG 只读挂载取出应用，复制到含中文和空格的新路径；核对应用版本 0.4.0、构建 20261102.1、独立测试版身份。
- 运行真实应用的隔离诊断：新库为空、包内运行路径存在、合成记录保存后重读成功。未启动正常身份的正式安装版。
- 用最终镜像取出的 Python 与后端，通过 39 项图文/文字 API 合成检查，含本机模拟服务的真实 HTTP 请求；未调用真实供应商、收费模型或个人密钥。
- 全新 HOME、仅系统 PATH 下，使用镜像内 Python、FFmpeg、Whisper 实际转写新生成的中文语音。结果包含繁体输出和个别识别误差，验证的是离线链路可运行，不能据此保证识别准确。
- 检查 110 个原生程序与库，无非系统绝对路径的外部动态库依赖；所声明的最低系统目标最高为 macOS 14。
- 复核已知私人内容指纹、凭据、个人路径、数据文件、公开语音模型 SHA-256 和嵌套签名；正式资料库与正式安装程序的前后校验值不变。
- **Gatekeeper 实际评估仍为拒绝：缺少 Developer ID 签名和 Apple 公证，此项未通过。**

未完成第二台实体 Mac、macOS 14 真机、跨机录音权限与系统音频链路验收。本轮未验收真实服务商的图文模型质量、实际课程截图识别、所有界面交互或所有旧资料的升级。回归与合成检查通过不等于这些项目已验证。

语音识别、图像解读、AI 概括与来源关联仍可能出错，请回查原图、原稿和录音。更新前备份完整测试版资料目录；旧版可能无法读取新版图片格式。
